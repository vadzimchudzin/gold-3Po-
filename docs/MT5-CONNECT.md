# Подключение GOLD-3Po к MetaTrader 5

GOLD-3Po подключается к терминалу MT5 вашего брокера, получает котировки золота,
рассчитывает уровни ликвидности и передаёт их **отдельному индикатору** на график.
Приложение не отправляет и не изменяет ордера.

## Архитектура

```
GOLD-3Po (Electron)                    MetaTrader 5
┌─────────────────────────┐            ┌──────────────────────────┐
│ Автопоиск MT5           │──офиц. SDK─▶│ уже авторизованный MT5    │
│ зоны по ТФ из настроек  │            │                          │
│ публикация снапшота     │──файл─────▶│ индикатор Gold3PoLevels  │
└─────────────────────────┘  Common    │ рисует уровни на графике │
                             Files     └──────────────────────────┘
```

- На старте приложение находит запущенный `terminal64.exe` текущего пользователя и подключается к нему через официальный Python-модуль MetaTrader5.
- Коннектор проверяет уже активную сессию через `terminal_info()` и `account_info()`. Он не вызывает `login()`, не спрашивает пароль и не переключает счёт.
- Автопоиск подключается только к одному однозначно найденному запущенному терминалу. Если открыто несколько MT5, приложение не угадывает, к какому счёту подключаться.
- Рыночные события разделяются стабильным идентификатором брокерского сервера, счёта и символа. История, live-котировки, футпринт и зоны одного счёта не смешиваются с данными другого.
- Если видны несколько суффиксных инструментов золота и нет точного XAUUSD, коннектор не выбирает случайный контракт: он просит оставить видимым нужный символ.
- Автоконнектор упакован в `mt5-runtime/gold3po-mt5/gold3po-mt5.exe` — отдельный Python не нужен.
- При каждом запуске приложение обновляет `Gold3PoBridge.mq5` и `Gold3PoLevels.mq5` в каталоге данных найденного терминала и компилирует их через MetaEditor, если он установлен рядом с терминалом.
- Локальный токен для EA автоматически публикуется в `Common\\Files\\GOLD3PO\\bridge-token.txt`; сам советник читает его, поэтому копировать токен в параметры вручную не требуется.
- Уровни публикуются атомарно в `…\MetaQuotes\Terminal\Common\Files\GOLD3PO\<СИМВОЛ>.csv`
  (символ в верхнем регистре, например `XAUUSDM.csv`). Индикатор читает этот файл
  каждые 2 секунды; сети не использует и DLL не требует.
- Лицензия GOLD-3Po проверяется при каждом обновлении: без действующего ключа
  публикация прекращается и индикатор очищает уровни по таймауту.

## Два способа подать котировки

| | Подключение приложения | Советник `Gold3PoBridge` |
|---|---|---|
| Что нужно | запущенный и авторизованный MT5 | один раз прикрепить скомпилированный EA к графику, разрешить WebRequest |
| История | последние ~8 часов или до 25 000 тиков | до 90 дней (по умолчанию 30), начиная за 8 часов до текущего времени |
| Live | приложение получает живые тики напрямую из MT5 | по умолчанию не дублирует live-поток приложения |
| Токен | используется локально приложением | EA автоматически читает его из Common Files |

Разделение ролей: приложение передаёт последние ~8 часов и живые котировки, а `Gold3PoBridge` догружает более старую историю и может рисовать зоны. Для обоих источников цена свечи согласована с режимом графика MT5: Bid для Bid-chart, Last для Last-chart. Советник устанавливается и компилируется автоматически, но MT5 не позволяет приложению незаметно прикрепить EA к графику: прикрепите его один раз вручную, если нужна глубокая история. Не запускайте советник одновременно на H1, H4 и M15: достаточно одного экземпляра на символ. Параметр `AppConnectionFeedsLive` оставьте включённым.

## Пошагово

1. Открой MT5 и войди в нужный счёт обычным способом. Добавь инструмент золота брокера в «Обзор рынка» (например, `XAUUSD`, `XAUUSDm` или `XAUUSD.pro`).
2. Запусти GOLD-3Po. При запуске оно само найдёт уже запущенный MT5, проверит активный счёт и выберет доступный символ золота. Поля логина, пароля и сервера не показываются; приложение не вызывает `login()`.
3. После подключения GOLD-3Po автоматически скопирует `Gold3PoBridge.mq5` в `MQL5\\Experts`, `Gold3PoLevels.mq5` в `MQL5\\Indicators` и попытается скомпилировать оба через MetaEditor. При повторной установке или каждом запуске выполняется такая же проверка/починка.
4. Если на компьютере открыто несколько терминалов MT5, закрой лишние и нажми «Найти и подключить MT5» ещё раз. Приложение намеренно не выбирает счёт наугад.
5. Если `MetaEditor64.exe` отсутствует рядом с терминалом, исходники всё равно будут скопированы; открой их в MetaEditor вручную и нажми F7.
6. Чтобы индикатор отображал зоны на графике, прикрепи `Gold3PoLevels` к XAUUSD один раз. Уже прикреплённый индикатор может потребовать перезапуска графика, чтобы загрузить обновлённый `.ex5`.
7. Для глубокой истории (до 30 дней) прикрепи `Gold3PoBridge` к одному графику XAUUSD. В MT5 один раз разреши WebRequest к `http://127.0.0.1:8787` в **Сервис → Настройки → Советники**. Токен EA берёт автоматически из Common Files; вводить его вручную не нужно.
8. Оставь `AppConnectionFeedsLive=true`: приложение передаёт live, советник догружает более старую историю и рисует зоны. Советник не отправляет, не изменяет и не закрывает ордера.


## Если советник не запускается или не получает зоны

- Перед стартом советник проверяет `GET /health`. Если приложение закрыто или WebRequest не разрешён, он не запускает загрузку истории и показывает причину во вкладке «Эксперты».
- В MT5 добавьте корневой адрес `http://127.0.0.1:8787` в **Сервис → Настройки → Советники → Разрешить WebRequest**. Разрешение требуется и для GET, и для POST.
- При `MQL5 error=5203` MT5 не завершил HTTP-запрос. Проверьте, что GOLD-3Po открыто и `/health` отдаёт `status: ok`, затем проверьте allow-list и перезапустите терминал. Это транспортная ошибка терминала, а не код отказа токена API.
- При HTTP 401/403/503 проверьте, что `IngestToken` скопирован из **Настройки → Отрисовка в MT5 → Мост MT5** без пробелов. После изменения параметра перезапустите советник.
- Если журнал показывает `GOLD-3Po zones: N`, API и отрисовка EA получили N зон. Если N равно 0, откройте `http://127.0.0.1:8787/v1/chart/zones?symbol=XAUUSD` на том же компьютере и проверьте поле `zones`.

## Масштабирование мышью

- График: зажми **Ctrl** и прокручивай колесо — горизонтальный масштаб; **Ctrl + Shift + колесо** — вертикальный ценовой масштаб.
- Футпринт: **Ctrl + колесо** — ширина столбцов; **Ctrl + Shift + колесо** — высота ценовых строк.
- Обычное колесо остаётся прокруткой рабочей области/футпринта.

## Трей

Сворачивание и закрытие окна прячут приложение в трей — локальный сервис и
поток котировок продолжают работать. «Open» / двойной клик по иконке возвращают
окно; **«Exit»** полностью завершает приложение и очищает снапшот уровней.

## Если MT5 не подключается

Окно показывает причину, которую сообщает сам терминал, — своего текста про
«проверьте путь» там больше нет:

- **«Модуль подключения MT5 не найден: <путь>»** — сборка пришла без коннектора;
  лечится переустановкой, а не настройками.
- **«В MT5 нет подтверждённого авторизованного счёта»** — приложение не выполняет вход вместо пользователя. Открой MT5, войди в нужный счёт непосредственно в терминале и повтори подключение.
- **«Не найден запущенный MetaTrader 5»** — сначала открой MT5 и войди в счёт вручную, затем повтори подключение из GOLD-3Po.
- **«Найдено несколько запущенных терминалов MT5»** — оставь открытым только тот терминал, с которым должна работать программа.
- **«Терминал MT5 открыт, но не подключён к брокеру»** — приложение не выполняет вход за тебя; проверь авторизацию в самом MT5.

## Важные ограничения

- Вход через официальный SDK может **запустить терминал и переключить активный
  счёт** в выбранной установке. Используйте отдельную установку терминала для
  GOLD-3Po, если не хотите затрагивать рабочий терминал с советниками.
- MFA, сертификаты и принудительная смена пароля выполняются в самом MT5.
- Зоны — ценовые области, где рынок уже разворачивался. Уровни собираются из
  нескольких независимых источников на закрытых барах выбранного таймфрейма:
  свинги, максимум и минимум прошлого дня, экстремумы сессий Азия / Лондон /
  Нью-Йорк, открытие и экстремумы прошлой недели, свинги H1 и H4, профиль объёма
  (POC и границы зоны стоимости) и круглые цены. Совпадение нескольких
  источников поднимает силу зоны. Все расстояния считаются в ATR. Уровень,
  пробитый один раз, остаётся как «role flip» (поддержка ↔ сопротивление);
  уровень, который цена пробивала туда-обратно, удаляется. Сила 0–100 % —
  рейтинг по измеренной реакции, касаниям, свежести, объёму, совпадению
  источников и близости к цене, а не откалиброванная вероятность. Это не стакан
  и не гарантия реакции цены.

## Формат снапшота (G3P2)

`Common\Files\GOLD3PO\<SYMBOL>.csv`, CRLF:

```
G3P2,<unix-время>,<символ>,<число зон>
STYLE,<#цвет выше>,<#цвет ниже>,<SOLID|DASH|DOT|DASHDOT|DASHDOTDOT>,<толщина 1-5>,<заливка 0/1>,<подписи 0/1>,<сила 0/1>
<id>,<buy-side|sell-side>,<low>,<high>,<сила 0-1>,<состояние>,<подпись>
...
END
```

Индикатор также принимает старый формат G3P1 (без строки STYLE).
- Поля «состояние» и «подпись» пишутся по-русски теми же словами, что и в панели
  приложения («Максимум прошлого дня», «ПРОВЕРЕНА»): подпись на графике MT5 и
  список зон в приложении читаются одинаково. Запятые, вертикальные черты и
  управляющие символы из подписи вырезаются, поэтому CSV не ломается.
  Файл пишется в UTF-8; индикатор читает его с кодовой страницей CP_UTF8.
- История при подключении ограничена последними ~8 часами тиков брокера
  (до 25 000 тиков); далее поток накапливается. Если терминал отдал не весь
  поток, приложение пишет об этом в строке состояния MT5 («История MT5
  неполная»), а не выдаёт частичные данные за полные. Для глубокого бэктеста
  используйте отдельный EA-мост `Gold3PoBridge.mq5` (до 90 дней).
- EA-мост и индикатор можно использовать вместе: EA грузит историю и тики,
  индикатор рисует уровни из файла приложения.
